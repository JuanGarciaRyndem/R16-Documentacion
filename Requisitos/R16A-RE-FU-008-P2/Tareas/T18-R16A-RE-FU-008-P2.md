## Objetivo general

Implementar el servicio de envío de correos de alerta vía Brevo para notificar al equipo de operaciones cuando el Mailbot presenta errores o un correo llega al Dead Letter Queue.

## Objetivos específicos

1. Crear `Mailbot.Infrastructure\Notifications\BrevoNotificacionService.cs`.
2. Implementar método `EnviarAlerta(asunto, cuerpo, destinatarios)`.
3. Configurar API key de Brevo y destinatarios vía `appsettings.json`.
4. Crear interfaz `INotificacionService` en `Mailbot.Domain\Interfaces\` si no existe.

## Resultado esperado

- El Worker puede enviar alertas por correo al equipo de operaciones cuando un evento falla después de agotar reintentos.

## Entregables

- `BrevoNotificacionService.cs`
- Interfaz `INotificacionService.cs` (si aplica)
- Configuración en `appsettings.json`

## Criterios de aceptación

- [ ] Se puede enviar un correo de prueba vía Brevo exitosamente.
- [ ] La API key se gestiona vía configuración (no hardcodeada).
- [ ] El servicio es invocado cuando un evento llega al DLQ (integración con lógica de reintentos).
- [ ] El proyecto compila sin errores.
