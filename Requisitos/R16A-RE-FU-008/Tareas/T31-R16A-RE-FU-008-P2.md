## Objetivo general

Exponer el endpoint `GET /api/buzon/pedidos` en `WebApi.Catalogos` que retorna la lista paginada del Buzón de Pedidos filtrada por el Agente Comercial y región del token.

## Objetivos específicos

1. Crear controller `WebApi.Catalogos\Controllers\Buzones\BuzonPedidosController.cs`.
2. Implementar `GET /api/buzon/pedidos` que acepta parámetros de paginación y filtros (texto, fecha, leído/no leído) vía query string.
3. Obtener `IdUsuario` e `IdRegion` del token mediante el patrón de autenticación existente.
4. Invocar `BuzonPedidosBO` y retornar el resultado paginado.
5. Aplicar atributo de autorización para rol de Agente Comercial.

## Resultado esperado

- `GET /api/buzon/pedidos` retorna la lista paginada de correos de pedido visibles para el Agente autenticado, segregados por región.

## Entregables

- `WebApi.Catalogos\Controllers\Buzones\BuzonPedidosController.cs`

## Criterios de aceptación

- [ ] `GET /api/buzon/pedidos` retorna `200 OK` con estructura paginada.
- [ ] El `IdUsuario` e `IdRegion` se extraen del token — no de parámetros externos.
- [ ] Soporta filtros múltiples (texto, fecha, leído/no leído) vía query string.
- [ ] Sin token válido retorna `401 Unauthorized`.
- [ ] El proyecto `WebApi.Catalogos` compila sin errores.
